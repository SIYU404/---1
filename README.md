# 都市生存探索 3D (Urban Survival FPS)

一款基於 **Three.js (WebGL 3D)** 與原生 JavaScript 打造的第一人稱開放世界都市探索與生存冒險遊戲。**支援 PC 電腦與手機 / 平板觸控直覺操作！**

---

## 🎮 操控方式 (極簡直覺化)

### 📱 手機 / 平板觸控螢幕操作 (無需多餘按鍵！)：
- **左側虛擬滑桿搖桿**：前後左右 360° 滑桿走動
- **右側滑動**：滑動螢幕旋轉視角
- **👆 點擊物品即拾取**：在螢幕上直接點擊任何食物、急救繃帶、醫療箱或武器即可立即拾取！
- **👆 點擊人物即攻擊**：在螢幕上直接點擊任何暴徒或路人即可立即發動武器揮擊或射擊！
- **🦘 跳躍按鈕**：點擊跳躍，在水中點擊上浮換氣
- **🏃 奔跑按鈕**：點擊切換加速快跑模式

### 💻 PC 電腦鍵盤滑鼠操作：
- `W` / `A` / `S` / `D`：前後左右平移走動
- `滑鼠`：360° 環顧視角
- `Shift`：奔跑加速
- `Space (空白鍵)`：跳躍 / 水中上浮
- `滑鼠左鍵點擊`：直接點擊目標人物/暴徒攻擊、點擊物資直接拾取
- `E 鍵`：靠近物資時亦可按 E 快速拾取

## 🌟 核心特色系統

1. **💖 補血與生理指標系統**：
   - **❤️ 生命值 (HP)**：受到車輛撞擊、暴徒毆打、飢餓或溺水時扣減。
   - **🩹 醫療品拾取補血**：地圖與室內刷新無菌繃帶 (+35 HP)、專業急救箱 (+75 HP)、止痛藥與熱騰騰拉麵。
   - **⚔️ 擊殺吸血回血**：擊倒暴徒立即觸發吸血回復 +18 HP 並掉落補給！
   - **🍗 飽足感 (Hunger)**：時間流逝遞減，空腹扣血；食用食物即時恢復。
   - **🤿 水中閉氣 (Breath: 60s)**：進入運河水下倒數 60 秒，超時溺斃，浮出水面快速回氧。

2. **🏪 4 棟可進入的室內特色建築**：
   - **🏪 24H 賽博便利超商** (`X: -34, Z: -35`)：貨架陳列大量零食與急救繃帶。
   - **🏥 都市急救診所 & 藥局** (`X: 34, Z: 35`)：常駐專業急救醫療箱與藥品。
   - **🍜 深夜熱騰騰拉麵屋** (`X: -34, Z: 35`)：暖色木質吧檯，提供叉燒拉麵 (+55%飽足, +35HP)。
   - **⚡ 軍火安全避難所** (`X: 34, Z: -35`)：槍械彈藥與醫療補給。

3. **👥 大規模都市路人與交通**：
   - **45+ 位 NPC**：路人散步、店員看店與暗巷暴徒巡邏。
   - **疾馳車輛**：大道隨機衝出狂飆車輛，過馬路請小心避讓。
