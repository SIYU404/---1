# 都市生存探索 3D (Urban Survival FPS)

一款基於 **Three.js (WebGL 3D)** 與原生 JavaScript 打造的第一人稱開放世界都市探索與生存冒險遊戲。

---

## 🎮 遊戲背景與玩法介紹

你孤身一人置身於繁華而危險的現代都市中。在這裡，你需要時刻關注自己的生理狀態，並在都市各處搜刮資源、防範危險、擊敗敵對暴徒。

### 🌟 核心特色系統

1. **第一人稱視角與動作控制**：
   - `W` / `A` / `S` / `D`：前後左右移動
   - `滑鼠移動`：360度環顧與視角轉換（點擊螢幕鎖定游標）
   - `Shift`：奔跑加速
   - `Space (空白鍵)`：跳躍 / 在水中向上浮升
   - `滑鼠左鍵`：使用當前武器進行近戰揮擊或遠程射擊
   - `E 鍵`：靠近物品時拾取食物或裝備武器

2. **生理指標管理**：
   - **❤️ 生命值 (HP)**：受到車輛撞擊、暴徒毆打、飢餓或溺水時扣減；歸零時 Game Over 死亡。
   - **🍗 飽足感 (Hunger)**：隨時間流逝逐漸消耗。飽足感降至 0% 時會進入飢餓狀態，持續扣除 HP。食用搜刮到的食物可補充飽足感並恢復血量。
   - **🤿 水中閉氣 (Breath)**：跳入都市中央的運河水面下時，會自動切換為水下視角並開始 **60 秒** 閉氣倒數。浮出水面會迅速回氧；若憋氣超過 60 秒氧氣耗盡將會窒息溺斃。

3. **都市動態危險與交通**：
   - **疾馳車輛**：街道上隨時有車輛呼嘯而過或衝出，過馬路時請小心觀察，被車撞到會承受巨大衝撞傷害！
   - **正常路人 vs 危險暴徒**：街頭隨機生成路人，其中危險暴徒發現玩家後會拔出武器主動追擊並攻擊玩家。

4. **武器搜刮與反擊戰鬥**：
   - 可以在建築內外、暗巷搜刮到 **木製棒球棍**、**鋼製鐵撬**、**9mm 手槍** 與彈匣。
   - 遭遇危險暴徒時，可使用武器發動攻擊，命中時具有擊退硬直、受擊音效與打擊回饋。
   - 擊倒暴徒後會掉落食物、彈藥或戰利品！

5. **現代風格 HUD 與雷達小地圖**：
   - 右上角配備實時雷達掃描（黃色為車輛、紅色為暴徒、綠/藍色為食物與武器、藍色為運河）。
   - 水下藍色濾鏡與泡泡氛圍、受傷紅芒、擊中反饋與事件日誌。

---

## 🚀 如何啟動遊戲

1. 直接使用任何現代瀏覽器（Google Chrome、Edge、Firefox 等）打開專案目錄中的 `index.html`。
2. 點擊畫面中央的 **「開始進入都市」** 按鈕即可鎖定滑鼠並進入第一人稱視角暢玩！
