# 都市生存探索 3D (Urban Survival FPS)

一款基於 **Three.js (WebGL 3D)** 與原生 JavaScript 打造的第一人稱開放世界都市探索與生存冒險遊戲。**支援 PC 電腦與手機 / 平板觸控響應式操控！**

---

## 🎮 操作指南

### 💻 PC 電腦鍵盤滑鼠操作：
- `W` / `A` / `S` / `D`：前後左右移動
- `滑鼠移動`：360° 環顧視角（點擊螢幕鎖定游標）
- `Shift`：奔跑加速
- `Space (空白鍵)`：跳躍 / 水中上浮
- `滑鼠左鍵`：使用當前武器進行近戰揮擊或遠程射擊
- `E 鍵`：靠近物品時拾取食物或裝備武器

### 📱 手機 / 平板觸控螢幕操作 (自動切換)：
- **螢幕左側虛擬搖桿 / 滑桿**：前後左右 360° 滑動控制角色走動
- **螢幕右側滑動**：手指滑動旋轉相機視角
- **⚔️ 攻擊按鈕**：點擊發動武器揮擊或開火攻擊
- **🦘 跳躍按鈕**：點擊跳躍，落入水中時點擊向上浮升換氣
- **✋ 拾取按鈕**：靠近物資時點擊拾取食物或裝備武器
- **🏃 奔跑按鈕**：點擊切換加速快跑模式

## 🌟 核心特色系統

1. **生理指標管理**：
   - **❤️ 生命值 (HP)**：受到車輛撞擊、暴徒毆打、飢餓或溺水時扣減；歸零時 Game Over 死亡。
   - **🍗 飽足感 (Hunger)**：隨時間流逝逐漸消耗。降至 0% 時進入飢餓狀態持續扣 HP。食用搜刮到的食物可補充飽足感並恢復血量。
   - **🤿 水中閉氣 (Breath)**：跳入都市中央運河水下時，開啟 **60 秒** 閉氣倒數。超時將會溺斃；浮出水面會迅速回氧。

2. **都市動態危險與交通**：
   - **疾馳車輛**：街道上隨時有車輛呼嘯而過或衝出，過馬路時請小心觀察，被車撞到會承受衝撞重創！
   - **正常路人 vs 危險暴徒**：街頭隨機生成路人與危險暴徒，暴徒發現玩家後會拔出武器主動追擊並攻擊玩家。

3. **武器搜刮與反擊戰鬥**：
   - 在建築內外、暗巷搜刮 **木製棒球棍**、**鋼製鐵撬**、**9mm 手槍** 與彈匣。
   - 擊倒暴徒後會掉落食物、彈藥等補給品！

4. **現代風格 HUD 與雷達小地圖**：
   - 右上角配備實時雷達掃描（黃色為車輛、紅色為暴徒、綠/藍色為食物與武器、藍色為運河）。
   - 水下藍色濾鏡與氣泡、受傷紅芒、擊中反饋與事件日誌。

## 🚀 如何啟動遊戲

1. 直接使用任何現代瀏覽器（Google Chrome、Edge、Safari、Firefox 等）打開專案目錄中的 `index.html`。
2. 點擊畫面中央的 **「進入遊戲」** 按鈕即可暢玩！
